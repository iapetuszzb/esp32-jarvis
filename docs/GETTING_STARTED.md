# 手机、摄像头首次使用

## 1. 安装安卓 App 并连服务器

1. 在手机浏览器打开本仓库 Release，下载正式 APK，允许该浏览器安装应用。App 名称是“Jarvis 视觉助手”。
2. 通过私下传输把 `connection.json` 送到手机，在 App 点击“导入连接配置 JSON”。文件包含服务器地址、访问密钥和会话 ID，应像密码一样保管。
3. 也可以填服务器地址，输入私下提供的 **一次性配对码**，点击“使用配对码连接”。配对码在当前服务启动后默认 24 小时有效、成功使用一次即失效；重启不会恢复已使用的码。过期后仍可导入 JSON，或由管理员换一个新码。
4. 点击“保存并检查连接”。尚未接摄像头时，应显示“服务器在线 · 等待同一会话的摄像头画面”。

首次发布的 APK 预填了本次临时测试服务器地址，但没有嵌入密钥。临时 HTTPS 隧道重建会换地址；导入新的 JSON 就能更新，无需重新安装 APK。正式长期使用建议换成固定域名。

## 2. 烧录 ESP32

按 [烧录说明](../firmware/FLASHING.md) 写入 Release 的固件包。必须确认开发板 GPIO、8 MB Flash 与 OPI PSRAM 配置相符。首次验证时用稳定 USB 供电，串口 115200。

## 3. 手机热点配网

1. 在手机热点设置中记下热点名称与密码，频段选 **2.4 GHz**，安全设置使用 WPA2 兼容模式。然后暂时关闭热点。
2. 手机 Wi-Fi 连上 `Jarvis-Cam-xxxxxx`，密码 `jarvis-setup`。它没有互联网；系统提示时选择继续连接，避免自动切到其他 Wi-Fi。
3. 在 App 下方“摄像头首次配网”填刚才的热点名称和密码，点“把连接配置写入摄像头”。服务器地址、密钥与会话 ID 会一起写入。
4. 如 App 配网失败，在浏览器打开 `http://192.168.4.1` 手填。使用连接 JSON 中的同一套服务器配置。
5. 离开摄像头 Wi-Fi，开启手机热点。ESP32 连接后直接上传 JPEG，App 使用手机移动数据查看状态。目标状态是“摄像头在线”。
6. 配网窗口默认 10 分钟。以后要改服务器或热点，按住 BOOT 约 3 秒重新打开，再重复配网。

此流程不要求手机同时充当 Wi-Fi 客户端与热点。重新配网期间相机会暂时离线；正常运行期间手机仅提供热点，App 无需持续连摄像头的 SoftAP。

## 4. 耳机与唤醒

1. 在系统蓝牙中配对 Enco R4，开启“通话音频”和媒体播放。
2. 首先点“立即开始对话”，授予麦克风、附近设备和通知权限。观察 App 的麦克风状态。它应显示蓝牙耳机；如果显示手机麦克风，说明当前未取得耳机通话通道。
3. 面对摄像头问“你看到了什么？”，检查耳机能否听到回答。蓝牙 HFP 会以通话音质工作，这是同时使用耳机麦克风的正常取舍。
4. 点击“结束本轮，继续等待唤醒”，再说英文 **Hey Jarvis**，等显示“正在看、听”后再提问。唤醒词本身不上传服务器；连接准备期间的语音会丢弃，因此首次联调请留出等待时间。
5. 在 ColorOS 应用电池设置中允许后台活动，保持前台麦克风通知，取消该 App 的电池优化。锁屏 5、15、30 分钟分别验证唤醒和蓝牙路由；系统强制结束 App 后需要手动开启。

建议先关闭“持续观察”，完成基本收音、画面和播放验证，再开启它。该模式让云端保持实时会话并允许主动描述；单轮 10 分钟结束后需手动重新开始。当前版不保证自动打断已排队的语音，遇到回声或积压时先结束本轮。

## 常见问题

| 现象 | 检查 |
|---|---|
| 摄像头不上线 | 2.4 GHz、热点名密码、排线、供电；串口 `Camera init failed` / HTTP 状态；手机移动数据是否通 |
| 等待 NTP / TLS 失败 | 热点能否访问互联网、NTP 是否被拦截、云端证书是否属于固件内可信 CA、服务器地址是否变动 |
| HTTP 401 | App 与 ESP32 密钥是否相同；不要把一次性配对码当作访问密钥 |
| App 在线但没有画面 | 摄像头必须使用同一会话 ID；超过 4 秒的画面不会用于推理 |
| 语音积压 / GPU 忙 | 结束其他会话，检查公网延迟；一个 GPU 同时只接受一个会话 |
| 耳机听得到但用手机收音 | 确认蓝牙通话音频开启、附近设备权限已授予，结束其他电话/录音 App 后重新开启 |
| 文字问题返回 409 | 先点击“结束本轮”，释放实时会话 GPU |
| 手机打不开服务 | 临时隧道可能已换域名；国内移动网络对海外隧道的连通性需实测，长期部署优先使用稳定、就近的 HTTPS 入口 |

图像只保留内存中的最新帧，2 分钟无人上传会清除缓存项；超过 4 秒即标记离线。音频按 1 秒分块处理。默认不持久保存用户媒体，但模型和基础设施仍会接触数据；临时入口经过 Cloudflare。访问密钥保存在手机应用私有目录、ESP32 NVS 与服务器私有配置中，没有额外硬件加密配置，不要公开连接 JSON。
